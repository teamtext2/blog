Kiến Trúc Web Tĩnh Serverless Với Cloudflare Workers Và GitHub API

Tác giả: Spac2 Dev • 05/11/2026 • 5 phút đọc

Trong thập kỷ vừa qua, phát triển web đã đi từ việc thuê máy chủ vật lý, VPS, đến container Docker và gần đây nhất là Edge Computing không máy chủ (Serverless). Spac2 Blog được xây dựng dựa trên nguyên lý triệt để: Zero Database, Pure Static Files, Globally Distributed.

1. Tại Sao Lại Chọn Cách Này?

Khi vận hành một blog nội dung, việc sử dụng các hệ quản trị nội dung nặng nề như WordPress hoặc cơ sở dữ liệu MySQL thường đi kèm với nhiều rủi ro:

  • Lỗ hổng bảo mật plugin và SQL injection.
  • Tốn chi phí duy trì máy chủ hàng tháng.
  • Thời gian tải trang chậm do phải kết nối cơ sở dữ liệu trên mỗi request.

2. Giải Pháp Git-based Content Swap

Thay vì lưu bài viết vào database, chúng tôi biến GitHub repository thành chính cơ sở dữ liệu phiên bản của mình. Cloudflare Worker chỉ đóng vai trò là một người gác cổng an toàn để tráo đổi nội dung tệp: 

// Worker tráo file tức thì
const updatedList = updateListJsContent(oldList, newPost);
await putGithubFile(config, "list.js", updatedList, commitMessage, sha);

Tất cả trang đều được lưu dưới dạng file HTML độc lập. Kết quả là tốc độ tải trang đạt mức tối ưu nhất trên toàn cầu nhờ mạng lưới CDN Anycast của Cloudflare.
